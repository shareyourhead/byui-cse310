# Overview

I am an experienced programmer, but I'm not sure I can consider myself a developer yet. I can write code, but that doesn't mean I have the experience necessary to integrate it into a larger environment. As such I decided to devote more time to writing "Hello World" programs.

This program does one thing, and one thing only. When it is run, it prints "Hello World!" to the terminal. This may seem like a simple function, and that's because it is. I was inspired my the minimalist mindset of the Shaolin Monks, who leave everything behind to sit around in the mountains feeding monkeys.

When one becomes deeply engrossed in their craft, it can happen that they begin to overlook the basics. In programming, these basics include several menial things such as, "How do I generate an SSH key for GitHub again?" and, "What was that incredible phrase that I'm supposed to print to the terminal when testing literally anything?" Though I've already forgotten the answer to the former, the answer to the latter is a resounding "HELLO WORLD!"
